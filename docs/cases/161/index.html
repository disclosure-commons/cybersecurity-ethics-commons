Case No.161

Dennis Giese and Braelynn Luedtke / Ecovacs Robot Security

Dual-Use Research · 2024

Security researchers Dennis Giese and Braelynn Luedtke reported vulnerabilities in Ecovacs robot vacuums that could allow unauthorized access to connected devices and their sensors. Their work raised questions about the security and privacy of smart-home devices and the appropriate timing of public disclosure.

Independent / contractor
Good faith (intended public benefit)
Responsible / coordinated
Public research disclosure and subsequent vendor security advisories

Key ethical dilemmas

(i) Should device owners be able to inspect and modify firmware despite vendor restrictions?; (ii) How much exploit detail is appropriate when it can help both defenders and attackers?; (iii) What privacy obligations arise when household sensors send data to vendor cloud services?; (iv) How can researchers promote user control without introducing new risks?
