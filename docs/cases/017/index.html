Case No.017

University of Hawaii & Notre Dame (AI/ML Hijacking)

Vulnerability Disclosure · ~2022

Researchers identified a supply-chain vulnerability in AI/ML model hosting platforms. After vendors were non-responsive, researchers published publicly to pressure remediation.

Academic researcher
Good faith (intended public benefit)
Vendor non-responsive → public disclosure
No charges filed

Key ethical dilemmas

(i) How long must researchers wait before publishing when vendors are non-responsive?; (ii) Does 'publish or die' academic incentive conflict with responsible disclosure timelines?; (iii) Liability if publishing before patch leads to exploitation; (iv) Whether AI/ML supply-chain vulnerabilities require a different disclosure framework
