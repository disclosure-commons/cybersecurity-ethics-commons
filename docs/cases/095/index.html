Case No.095

slipstream / Impero Software

Institutional Suppression · 2015

slipstream published details and a working exploit for a vulnerability in Impero Education Pro, classroom-monitoring software installed on school computers. Impero's lawyers alleged breach of the user agreement, disclosure of confidential information and reputational damage. The information stayed public.

Independent / contractor
Good faith (intended public benefit)
Media-first
Civil threat

Key ethical dilemmas

(i) Full disclosure of a working exploit for software on children's school computers: pressure on the vendor or risk to students? (ii) Should researchers coordinate first even with vendors they expect to be hostile? (iii) Is a user agreement a valid basis for silencing security findings?
