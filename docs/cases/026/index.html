Case No.026

FBI / Operation Pacifier (Playpen / Tor)

Surveillance & Offensive Tools · 2014–2016

- playpen (tor network where users showed child sa material) - tor concealed ip address which made it difficult - FBi found the server but kept it on for 13 more days, to get users information (got a warrant to deploy a NIT which caused users computers to send identifying info back to investigators) - THey removed the section that promoted more production of material, but let the site run regularly, (if site was changed, people might flee/delete content) - led to rescue of victims, prosections, etc - defendants challenged the operation saying it exceeded the warrant authority, they did not disclose the NIT code therefore is the evidence valid?

Government / law enforcement
Good faith (intended public benefit)
None (withheld)
Courts split on admissibility; some cases dropped

Key ethical dilemmas

(i) Government use of malware as investigative technique without targeted warrants; (ii) Single warrant authorizing hacking of computers across 120+ countries; (iii) DOJ choosing to drop prosecutions rather than disclose offensive tools; (iv) Does fighting CSAM justify warrantless global hacking of Tor users?
