Case No.026

PunkSpider / QOMPLX (DEF CON)

Vulnerability Disclosure · 2021.0

QOMPLX relaunched PunkSpider at DEF CON — a tool that mass-crawls the web for SQL injection, XSS, and path-traversal vulnerabilities and publishes results in a searchable public database, exposing real flaws in Kickstarter and LendingTree before notification.

Corporate / private sector
Ambiguous / gray area (mixed or unclear intent)
Media-first
No charges filed

Key ethical dilemmas

(i) Public disclosure of vulnerabilities before vendor notification; (ii) Dual-use: security tool vs. attack enablement; (iii) Scanning sites without owner consent (potential CFAA exposure); (iv) Whether 'pressure through shame' is an ethical remediation strategy
