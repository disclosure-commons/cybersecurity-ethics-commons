Case No.171

PHP Foundation / Wiz / OpenAI / Calif

Vulnerability Disclosure · 2026

Security researchers from Calif, OpenAI, and Wiz discovered critical remote code execution vulnerabilities in PHP (CVE-2026-109618 and CVE-2026-109619) and coordinated disclosure with the PHP security team and distributors. The public release was scheduled for October 22, 2026. On October 20, an anonymous user prematurely leaked information about the vulnerabilities online, which spread through social media. Although the initial leak did not contain technical exploit details, a subsequent premature video release by Calif and an early patch distribution by Chainguard further disrupted the embargo. The PHP security team accelerated its release schedule to October 21, 2026, to reduce exposure before coordinated patches became available.

Key ethical dilemmas

(i) Is it ethical to disclose critical vulnerabilities before patches are available, even when disclosure could pressure vendors to respond faster? (ii) Do individuals who obtain confidential vulnerability information have an ethical obligation to respect coordinated disclosure agreements? (iii) Should researchers prioritize public awareness or adherence to disclosure timelines when millions of systems may be vulnerable? (iv) What responsibilities do researchers and distributors have when premature disclosures expose users to exploitation before patches are widely available?
