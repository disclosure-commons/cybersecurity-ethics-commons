Case No.131

Ed Felten / Sequoia Voting Systems

Critical Infrastructure & Public Trust · 2008
Chilling effect

Sequoia threatened legal action over a planned independent examination of its voting machines, and a judge suppressed the resulting report on voting machine security; as of October 2008 it remained unpublished.

Academic researcher
Good faith (intended public benefit)
None (withheld)
Civil suit / Injunction

Key ethical dilemmas

(i) Should voting machine vendors be able to block independent examination of systems used in public elections? (ii) Trade-secret claims versus voters' right to know. (iii) Should researchers accept engagements that a vendor can veto?
