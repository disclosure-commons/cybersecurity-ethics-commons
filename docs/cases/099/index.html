Case No.099

ESNC GmbH / PwC (ACE software for SAP)

Institutional Suppression · 2016

ESNC tried to coordinate disclosure of vulnerabilities in PwC's ACE software for SAP that could enable accounting fraud. PwC sent two cease-and-desist letters; ESNC published the vulnerabilities with a timeline anyway.

Corporate / private sector
Good faith (intended public benefit)
Responsible/coordinated
Civil threat

Key ethical dilemmas

(i) Should researchers publish after a cease-and-desist when the flaw could enable financial fraud? (ii) Does an auditing firm's own software deserve stricter scrutiny? (iii) How much detail is safe when the affected systems run companies' financial controls?
