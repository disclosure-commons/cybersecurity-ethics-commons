Case No.119

Don Weber (InGuardians) / Smart Meter Vendor

Critical Infrastructure & Public Trust · 2012
Chilling effect

Weber cancelled the ShmooCon 2012 release of a free smart-meter security testing tool, citing a wish to work with the vendor, and later presented at BSidesLV 2012. A source told Attrition that InGuardians contacted the vendor only weeks after the CFP, raising the possibility the vendor became a client.

Corporate / private sector
Ambiguous / gray area (mixed or unclear intent)
Responsible/coordinated
Talk withdrawn (later presented)

Key ethical dilemmas

(i) When a vendor becomes a client, can the researcher still decide disclosure independently? (ii) Should a testing tool for critical infrastructure be released freely? (iii) Is it fair to the community to withdraw a scheduled talk for commercial reasons?
