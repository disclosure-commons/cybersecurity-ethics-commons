Case No.149

Shadow Brokers / EternalBlue leak

Surveillance & Offensive Tools · 2016

Between 2016 and 2017, the Shadow Brokers released tools linked to the U.S. National Security Agency, including the Windows exploit known as EternalBlue. Microsoft patched the underlying vulnerability in March 2017, but the exploit's subsequent public release contributed to attacks such as WannaCry and NotPetya on systems that remained unpatched.

Journalist / activist / independent
Ambiguous / gray area (mixed or unclear intent)
Public leak
No charges filed for the leak itself

Key ethical dilemmas

(i) Should governments keep zero-days for intelligence or disclose them to vendors? (ii) Who is responsible for the harm the leaked exploit caused? (iii) How should exploit retention be overseen?
