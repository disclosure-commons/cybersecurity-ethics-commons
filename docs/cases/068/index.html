Case No.068

Bernstein v. US Dept. of State (Snuffle encryption export case)

Legal Boundaries & CFAA Overreach · 1995–1999
Chilling effect

UC Berkeley grad student Daniel Bernstein wrote an encryption program called 'Snuffle' and wanted to publish it and an academic paper explaining it. The State Department classified the software as a 'munition' under the International Traffic in Arms Regulations (ITAR), requiring an export license to publish. EFF represented Bernstein; the Ninth Circuit ultimately ruled that source code is speech protected by the First Amendment and that the ITAR licensing scheme was an unconstitutional prior restraint. The case was foundational in establishing that encryption source code is protected expression and helped end ITAR controls on encryption.

Academic researcher
Good faith (intended public benefit)
None (withheld)
Civil suit / Injunction

Key ethical dilemmas

(i) Is encryption source code 'speech' protected by the First Amendment, or purely functional 'conduct' that can be regulated without First Amendment scrutiny?; (ii) Can the government require a license before a researcher publishes an academic paper containing functional encryption code?; (iii) Do national security interests in controlling encryption export justify prior restraint on academic publication?; (iv) How should the law treat dual-use academic research that has both civilian security value and potential military/intelligence applications?
