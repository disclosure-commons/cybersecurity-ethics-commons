Case No.003

Andrew 'Weev' Auernheimer / AT&T (Arkansas)

Legal Boundaries & CFAA Overreach · 2010–2014
Chilling effect

- AT&Ts website showed iPad users email address through their public website. - two researchers ran a script to retrieve the information about 114,000 emails. - the exploit used the fact that at&t allocated sim cards for the ipad with no security checks to prevent anyone accessing the details - used url for public api, changed the numbers to get different emails - main guy went to jail, but people are petitioning for him to be released.

Independent / contractor
Ambiguous / gray area (mixed or unclear intent)
Media-first
Convicted (later overturned/expunged)

Key ethical dilemmas

(i) Is scraping publicly accessible but unintended data unauthorized access under CFAA?; (ii) Responsible disclosure vs. media disclosure to maximize embarrassment; (iii) Chilling effect on legitimate security research; (iv) Corporate negligence vs. researcher culpability
