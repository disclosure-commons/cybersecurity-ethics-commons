Case No.158

Shadow Brokers / EternalBlue leak

Surveillance & Offensive Tools · 2016–2017

in 2016-2017 a group calling itself the Shadow Brokers leaked tools linked to the NSA the leak included the EternalBlue exploit for Windows reporting says the NSA had known about the flaw for years and had not told Microsoft Microsoft patched it in March 2017 and the leak came a month later EternalBlue was then used in WannaCry (2017) and NotPetya many systems stayed unpatched, so harm continued

Journalist / activist / independent
Ambiguous / gray area (mixed or unclear intent)
Public leak
No charges filed for the leak itself

Key ethical dilemmas

(i) Should governments keep zero-days for intelligence or disclose them to vendors? (ii) Who is responsible for the harm the leaked exploit caused? (iii) How should exploit retention be overseen?
