Case No.155

Heartbleed / OpenSSL

Vulnerability Disclosure · 2014

Heartbleed (CVE-2014-0160), disclosed in April 2014, was a flaw in OpenSSL's heartbeat extension that could expose portions of server or client memory, including potentially sensitive credentials and cryptographic material. Coordinated patching and public warnings raised questions about the timing of disclosure for widely deployed open-source infrastructure.

Independent / contractor
Good faith (intended public benefit)
Responsible / coordinated
Patch and public disclosure

Key ethical dilemmas

(i) What obligations do maintainers of widely deployed security libraries have when their project is underfunded? (ii) How should organizations and funders distribute responsibility for software that is free to use but critical to security?
