Case No.031

Kennesaw State University / Georgia Election Server

Critical Infrastructure & Public Trust · 2016–2017
Chilling effect

Logan Lamb found Georgia's entire election infrastructure server publicly accessible at KSU, containing voter registration data, passwords, and election management files. KSU wiped the server before the FBI could examine it during the subsequent investigation.

Independent / contractor
Good faith (intended public benefit)
Responsible/coordinated
No charges filed (KSU; evidence destruction concerns)

Key ethical dilemmas

(i) Responsible disclosure failure when institutions do not respond to researcher notifications; (ii) Destruction of evidence after a researcher goes public; (iii) Whether researchers have an obligation to escalate beyond the institution when critical infrastructure is at risk; (iv) Accountability gap when election infrastructure is housed at an academic institution
