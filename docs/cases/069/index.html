Case No.069

Cobell v. Norton — BIA Internet Disconnection / Security Audit

Critical Infrastructure & Public Trust · 2001.0

In a class action over mismanagement of Native American trust accounts, a court-appointed security expert found that the Bureau of Indian Affairs' computer systems were so insecure that the judge ordered the entire Interior Department's internet connectivity disconnected until security could be verified. The case raised profound questions about what a court can order when government IT security failures endanger beneficiaries' financial data — and who bears accountability when critical government systems fail basic security standards.

Government / law enforcement
Good faith (intended public benefit)
Responsible/coordinated
Civil suit / Injunction

Key ethical dilemmas

(i) Can a court order a government agency to disconnect from the internet as a security remedy?; (ii) What accountability mechanisms exist when a government agency's repeated security failures endanger the financial data of a vulnerable population?; (iii) Who should conduct security audits of government systems — internal auditors, independent experts, or adversarial testers?; (iv) When a security audit reveals catastrophic failure, how should findings be disclosed without creating additional risk?
