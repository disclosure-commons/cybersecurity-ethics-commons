Case No.066

Apple v. Corellium

Institutional Suppression · 2019
Chilling effect

Apple sued Corellium over virtualized iOS technology used by security researchers to inspect software and test vulnerabilities. Courts considered copyright and fair-use issues, and an appeals court held that Corellium's virtualization could qualify as fair use while remanding some issues. The dispute illustrates how intellectual-property enforcement can affect security research tools.

Corporate / private sector
Good faith (intended public benefit)
Responsible/coordinated
Civil copyright litigation; substantial fair-use ruling for Corellium

Key ethical dilemmas

(i) Copyright vs. security research; (ii) Research tool legality; (iii) Vendor retaliation
