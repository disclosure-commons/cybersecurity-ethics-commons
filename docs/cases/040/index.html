Case No.040

Josh Renaud / Missouri DESE (St. Louis Post-Dispatch)

Institutional Suppression · 2021.0
Chilling effect

Reporter Josh Renaud found teacher Social Security numbers exposed in a state website's HTML source code, verified it responsibly, and waited for a fix before publishing. Missouri Governor Parson publicly called him a 'hacker' and referred the case to prosecutors. No criminal intent was found; case was closed without charges.

Journalist / activist / independent
Good faith (intended public benefit)
Responsible/coordinated
No charges filed

Key ethical dilemmas

(i) Should governments be able to relabel 'view source' inspection as criminal hacking to deflect blame?; (ii) Press freedom vs. official retaliation for embarrassing disclosures; (iii) Use of vague hacking rhetoric to chill future security journalism
