Case No.162

CrowdStrike global outage

Critical Infrastructure & Public Trust · 2024

on July 19, 2024 CrowdStrike pushed a faulty content update to its Falcon sensor on Windows machines millions of machines crashed into boot loops, disrupting airlines, hospitals, banks, and emergency services the cause was a software error in a rapid-response content update, not an attack the update went to all customers at once rather than in stages fixes required manual repair on many machines, so recovery took days CrowdStrike published a root-cause analysis and promised staged rollouts and more testing scammers also exploited the confusion with fake fixes

Corporate / private sector
Accidental / negligent
Public incident disclosure
Global outage and remediation

Key ethical dilemmas

(i) Should security vendors be liable for outages their products cause? (ii) Does deep system access by security tools create too much risk for the protection it gives? (iii) How fast should urgent security updates ship vs. how carefully should they be tested?
