Case No.065

Universal City Studios v. Corley / Reimerdes (DeCSS / DMCA)

Institutional Suppression · 2000–2001
Chilling effect

2600 Magazine publisher Eric Corley (Emmanuel Goldstein) posted the DeCSS code — a program that decrypted DVD copy protection — on his website and linked to other sites hosting it. The movie studios sued under the DMCA's anti-trafficking provision. The Second Circuit upheld the injunction, ruling that computer code posting is regulable conduct under intermediate First Amendment scrutiny and that the DMCA's anti-trafficking provision was constitutional. The case became the defining early test of whether publishing security-relevant code is protected speech.

Journalist / activist / independent
Good faith (intended public benefit)
Media-first
Civil suit / Injunction

Key ethical dilemmas

(i) Is publishing functional security/encryption code protected First Amendment speech?; (ii) Can the DMCA's anti-trafficking provision constitutionally prohibit publication of code that has legitimate research and interoperability uses?; (iii) Does linking to a site hosting prohibited code make a publisher liable under the DMCA?; (iv) Who gets to define the boundary between security research tools and circumvention devices?
