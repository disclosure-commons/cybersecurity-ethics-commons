Case No.012

University of Birmingham (Keylogging)

Dual-Use Research · ~2017

Birmingham researchers studied keylogging malware behavior in a controlled lab, producing detailed technical documentation of how to implement effective keyloggers and evade detection — with obvious dual-use potential.

Academic researcher
Good faith (intended public benefit)
Responsible/coordinated
No charges filed

Key ethical dilemmas

(i) Dual-use documentation: keylogger implementation guides as academic research; (ii) Unregulated OS/sensor access as research methodology; (iii) Deception inherent in research design; (iv) Whether publication of offensive tool techniques requires prior vendor notification
