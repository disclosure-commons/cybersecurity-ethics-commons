Case No.110

Joshua Rogers / Public Transport Victoria

Vulnerability Disclosure · 2014
Chilling effect

Rogers, a schoolboy, found security flaws in the Public Transport Victoria website that exposed customer data and reported them. PTV referred the incident to Victoria Police.

Student
Good faith (intended public benefit)
Responsible/coordinated
Police referral (no charges reported)

Key ethical dilemmas

(i) Should a teenager's good-faith report be handled differently from an adult's? (ii) Police referral as a default response: protecting customers or deterring reporters? (iii) How much access is acceptable to confirm customer data is exposed?
