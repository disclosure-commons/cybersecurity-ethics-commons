Case No.152

Microsoft Exchange ProxyLogon Exploitation

Vulnerability Disclosure · 2021

In early 2021, attackers exploited previously unknown vulnerabilities in on-premises Microsoft Exchange servers and installed web shells for persistent access. Microsoft issued security updates, but patching alone did not remove already-installed shells. In April, the U.S. Justice Department announced a court-authorized FBI operation to remove malicious web shells from hundreds of U.S. servers without advance owner consent.

Government / law enforcement
Ambiguous / gray area (mixed or unclear intent)
Vendor disclosure and later remediation
Mass exploitation and emergency remediation

Key ethical dilemmas

(i) Should the government be able to access private systems without consent to fix a security problem? (ii) Who is responsible for cleanup when owners cannot or will not do it? (iii) Does a court order make it ethical if owners are not told first?
