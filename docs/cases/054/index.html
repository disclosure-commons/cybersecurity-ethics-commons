Case No.054

Dragon Sector / Newag SA (Poland)

Institutional Suppression · 2026–present
Chilling effect

When Newag-built Impuls trains began locking up after independent-shop maintenance, Dragon Sector reverse-engineered the onboard software and found GPS-triggered lockout code designed to disable trains serviced by competitors. Newag sued for copyright infringement and defamation; at the first hearing Newag conceded researchers had not modified any train software.

Independent / contractor
Good faith (intended public benefit)
Media-first
Civil suit (ongoing)

Key ethical dilemmas

(i) Manufacturers using anti-repair 'DRM' embedded in safety-critical infrastructure; (ii) Suing researchers for exposing the lockout rather than addressing it (right-to-repair); (iii) Criminal investigations opened against disclosers rather than the manufacturer
