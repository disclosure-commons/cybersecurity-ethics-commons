Case No.059

Microsoft / Nightmare Eclipse (Windows Defender & BitLocker Zero-Days)

Vulnerability Disclosure · 2026
Chilling effect

In 2026, a researcher using the name Nightmare Eclipse released proof-of-concept code for multiple Windows vulnerabilities after alleging problems with Microsoft's disclosure and bounty process. Some techniques were later observed in intrusions, and Microsoft criticized the uncoordinated publication of exploitable flaws. Claims of account deletion, retaliation, and threatened prosecution should be attributed to the parties rather than treated as independently established facts.

Independent / contractor
Ambiguous / gray area (mixed or unclear intent)
Media-first
No charges filed

Key ethical dilemmas

(i) When a company allegedly mistreats a researcher — deleting their account, withholding bounty payments, removing attribution — does that researcher bear ethical responsibility for subsequently publishing unpatched vulnerabilities?; (ii) Is 'full disclosure' of an unpatched vulnerability ever ethically justified as a last resort against an unresponsive or hostile vendor?; (iii) Does threatening a researcher with criminal prosecution for disclosing bugs create a chilling effect that ultimately harms users more than the disclosure itself?; (iv) Who bears moral responsibility when a researcher-disclosed vulnerability is exploited in the wild — the researcher or the vendor that failed to patch it?
