Case No.015

David Levin / Vanguard Cybersecurity / Florida Elections

Legal Boundaries & CFAA Overreach · 2016.0
Chilling effect

Pen-tester David Levin tested SQL injection vulnerabilities on a Florida county elections website without written authorization and was arrested for unauthorized access.

Corporate / private sector
Good faith (intended public benefit)
None (withheld)
Charged / dropped

Key ethical dilemmas

(i) Unauthorized testing of public election infrastructure — crime or civic duty?; (ii) Whether pentesting without explicit written authorization can ever be 'ethical'; (iii) Chilling effect on election security research; (iv) Distinction between proof-of-concept testing and malicious intrusion
