Case No.004

Christopher Soghoian / Indiana University

Vulnerability Disclosure · 2006.0
Chilling effect

PhD student Soghoian built a web tool generating realistic fake TSA boarding passes to alert Congress to a long-known security flaw. The FBI raided his home; charges were eventually dropped.

Academic researcher
Good faith (intended public benefit)
Provocation
Charged / dropped

Key ethical dilemmas

(i) Is creating a working exploit to force policy change ethically justified?; (ii) Research freedom vs. real-world risk of tool misuse; (iii) Government pressure to suppress valid security findings; (iv) When does responsible disclosure become irresponsible provocation?
