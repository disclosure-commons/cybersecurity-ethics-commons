Case No.058

DVD Copy Control Assn v. Bunner (DeCSS — California)

Institutional Suppression · 2001–2003
Chilling effect

Bunner posted DeCSS on his site the DVD industry sued under California trade secret law instead of the DMCA state courts argued about whether DeCSS was still secret once posted widely California Supreme Court said an injunction wasn’t automatically a speech violation later the injunction was thrown out since it was no longer secret

Journalist / activist / independent
Good faith (intended public benefit)
Media-first
Civil suit / Injunction

Key ethical dilemmas

(i) Can trade secret law justify a prior restraint on publication of security-relevant code that has already spread widely on the internet?; (ii) At what point does information become 'too public' to still qualify as a protectable trade secret?; (iii) Does the First Amendment protect redistribution of security code even if the original acquisition was improper?; (iv) Should courts balance the chilling effect on security research before granting injunctions against code publication?
