Case No.011

Multiple Universities (Honeypot Research)

Informed Consent & Human Subjects · Ongoing

Security researchers at multiple institutions deploy honeypot systems to attract and log real attacker activity without consent. Some cases involve researcher interaction with attackers, raising entrapment concerns.

Academic researcher
Good faith (intended public benefit)
None (withheld)
No charges filed

Key ethical dilemmas

(i) Is studying criminal activity without consent ethical when 'subjects' are themselves acting illegally?; (ii) Entrapment vs. observation; (iii) Publishing attacker IP addresses and tools; (iv) Liability if honeypot is misused as a lateral pivot by attackers
