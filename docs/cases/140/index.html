Case No.140

Luigi Auriemma (PivX) / Epic Games

Institutional Suppression · 2003

Auriemma published vulnerabilities in the Unreal game engine and received a legal threat from Epic Games. The same day, Epic's Mark Rein apologized publicly, calling it a 'moment-of-stupidity' reaction.

Independent / contractor
Good faith (intended public benefit)
Research publication
Civil threat (withdrawn, apology)

Key ethical dilemmas

(i) Does a quick public apology repair the chilling effect of a threat? (ii) Should game engines used by millions be held to enterprise disclosure norms? (iii) Should researchers coordinate with game vendors before publishing?
