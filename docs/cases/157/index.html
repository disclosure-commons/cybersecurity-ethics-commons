Case No.157

Stuxnet

Critical Infrastructure & Public Trust · 2010

malware discovered in 2010 that targeted specific industrial control systems widely attributed to the US and Israel, though neither has officially confirmed it aimed at centrifuges at Iran’s Natanz nuclear facility it spread beyond its target through Windows vulnerabilities and USB drives used several zero-day exploits showed that software can cause physical damage

Government / intelligence
Malicious / reckless (knowingly harmful)
None (withheld)
No public criminal charges

Key ethical dilemmas

(i) Is a cyberattack on infrastructure different from a conventional strike? (ii) Is it acceptable to hoard and use zero-days that leave everyone else vulnerable? (iii) Who is accountable when the code escapes its target?
