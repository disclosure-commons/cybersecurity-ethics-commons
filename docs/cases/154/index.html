Case No.154

Harvard University Facebook Messenger -- Aran Khanna

Informed Consent & Human Subjects · Not specified
Chilling effect

student developed a chrome extension called "marauders map" used location coordinates already attached to facebook messenger messages to map movements released the extension to the public showing the privacy issue didn't consult facebook, FB asked to remove it and withdrew his internship facebook changed location sharing behavior no arrests/charges

Student
Good faith (intended public benefit)
Public disclosure after vendor response
No charges filed

Key ethical dilemmas

(i) Is it ethical to expose people's location just to demonstrate a privacy issue? (ii) Was publicly releasing the extension necessary? (iii) Is Facebook justified in withdrawing his internship? (iv) Is collecting existing data ethically different from creating new surveillance capabilities?
