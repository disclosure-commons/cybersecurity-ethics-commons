Case No.093

Digital Interruption / Giggle app

Vulnerability Disclosure · 2020
Chilling effect

Saskia Coplans of Digital Interruption tried to report a vulnerability in the women-only Giggle app that exposed users' account information, including location data and photos, first through Twitter direct messages. Giggle's CEO denied the issue for days, blocked the researchers and threatened legal action, then issued a conciliatory statement; the bug was eventually patched without acknowledgment.

Corporate / private sector
Good faith (intended public benefit)
Vendor non-responsive → public disclosure
Civil threat

Key ethical dilemmas

(i) Is reaching out over Twitter an acceptable disclosure channel when a vendor has no security contact? (ii) When a vendor denies a flaw exposing vulnerable users, how quickly should researchers go public? (iii) How should researchers respond when a disclosure becomes entangled in a political dispute about the app?
